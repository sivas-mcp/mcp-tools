Every Morning · First Thing
One search. Three News picks. One Trending Now widget.
This replaces the separate Daily News Loop and Trending Now Manager with a single morning routine. One 24-hour search produces a ranked candidate table — each with a real stat, a badge, a category tag, and a suggested internal link. The top candidates become today's 3 News pieces (write & publish first), and the same table feeds the Trending Now widget — including links to the News pieces you just published.

Trending Now entries that match today's News picks should link straight to those live URLs — that's the "intentional flow" this is designed around. Entries that don't match a fresh News piece fall back to Signal, an existing CareerIQ article, or a Career Path page (see Link Hierarchy below).

The 4-Step Workflow
Search → review → publish → link
Discovery, human review, today's content, and the Trending Now refresh all come from one session. Step 2 is the human checkpoint — you confirm the picks before anything gets written.
1
Run the Search & Assign prompt
~5 minutes
Paste the prompt above into Claude, Perplexity, or Gemini. You'll get back 10-12 ranked candidates, each with a category tag, a real stat + badge, a suggested link, and a [NEWS PICK] flag on the strongest ones.

2
Review candidates — get prompts for what you want to write
~2 minutes
Paste the candidate table into the Review Candidates panel above. Claude ranks all candidates in slate format with depth assignments. Click "Get Prompt" on any row — the T1 writing prompt appears pre-filled with the title and cluster, ready to copy into Claude. Write as many as your bandwidth allows today.

3
Write & publish
~30–40 minutes per piece
For each story you're writing: copy the Research prompt → paste into Perplexity → get notes. Then copy the Write Prompt → paste into Claude with the notes at the bottom → article written. Publish via WordPress.
Research + Write Prompt buttons above
If a piece doesn't go live today, its Trending Now slot falls back to the next link in the hierarchy — nothing breaks.

Where Each Entry Links To
Link Hierarchy
For every Trending Now entry, pick the first option below that genuinely fits — don't force a weak match higher up the list.
1
A News or CareerIQ article already on the site
Including the 3 pieces you just published this morning. Most direct — "we already covered this." As daily output accumulates, this becomes the default for most entries within a few weeks.
2
The Signal — report or live dashboard
AI Job Displacement Tracker, Entry-Level Job Market Monitor, or a current Theme/Sector Report. Evergreen and always live — the strongest fallback today, and your highest-value CTA regardless.
3
A specific Career Path page
When a named role is central to the story. Strongest long-term option given 833 pages, but only a couple are populated today — use when one of those happens to match.
4
MyCareerPal homepage
Last resort — only if nothing above genuinely fits.
Before the widget goes live on-site: since nothing's published to it yet, it's worth seeding a few more Signal pieces and News/CareerIQ articles first so early Trending Now widgets aren't entirely Signal-fallback links.
